# Quy chuẩn Frontend (React + Tailwind)

1. **Component**: Sử dụng Functional Components và Hooks. Chia nhỏ component tối đa (Atomic Design).
2. **Styling**: Sử dụng 100% Tailwind CSS. Không viết CSS thuần.
3. **State Management**: Ưu tiên sử dụng `React Query` cho server state và `Zustand` cho global client state.
4. **Icons**: Sử dụng bộ thư viện `Lucide React`.
5. **Form**: Luôn sử dụng `React Hook Form` kết hợp với `Zod` để validate dữ liệu đầu vào.
